# Noted-Frontier
Text based Visual RPG

## 🐱‍💻 How to work on an issue
From your IDE:
- There should be a GitHub tab at the bottom which shows what branch you are looking at
- Right-click `main` branch and select `Create new branch from main` or something along those lines
- Name this branch something meaningful like `ISSUEXX-add-something-feature` or `USER-add-someting-or-fix`short, specific.
- It should then automatically move you to that branch.
- Make your changes, make sure to test they work using your own environment 
- When you are done with your changes, there should be a tab on the side of your IDE that says `stage + commit`
- This will display the files you have changed and will have a checkbox next to them.
- Add a commit message. Make it short, to the point I don't need extra detail, I can see it.
- After just do `commit and push`, go to GitHub Repo in the Web
- There should be a pop-up that says like changes have been made, make a pull request
- Make a PR, set a title (Should be name of your branch `XXXXX-xxx-xxx-xxx`)
- Set a description, here you can explain your reasoning for doing certain stuff like I added this because....
- Scroll to the bottom and create PR
- Wait for me to review :3
